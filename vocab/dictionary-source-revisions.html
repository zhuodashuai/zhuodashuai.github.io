语法形态校订

“原有释义＋语法形态校订”表示中文释义保留原来源，当前使用的词性和词形链接经过另外记录的项目校订。它不是 ECDICT 原数据，也不是整部词典已获专家审定的声明。

本次仅涉及四条记录

  • are：当前释义指 be 的动词形式，因此使用动词标签；不把同形的面积单位名词套到该释义上。
  • did / had / been：保留原有动词标签与释义。
  • 这四条动词记录不再使用 ares / dids / hads / beens 作为其后续词形。这里只移除四条具体链接，不删除同形的独立词条或其他语境。

原始 MIT 数据、旧词性证据、原始词形列表及修订前后的完整记录均保留供核对。正常的 do → did、have → had、be → been 关联继续保留；个人词条、学习记录和书中原句不由这项校订修改。
