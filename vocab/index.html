Install the word cabinet

把秘密单词屋放到桌面

  1. 在 Chrome 或 Edge 中打开本页。
  2. 点击地址栏右侧的“安装”图标，或在浏览器菜单中选择“安装秘密单词屋”。
  3. 安装后会生成桌面／开始菜单快捷方式，并直接进入“我的秘密词库”。

首次联网打开后，主要界面可离线使用；自动释义、出处搜索和 GitHub 同步仍需要网络。

How should new words enter?

新词怎样进屋？

先选一次，以后可以随时在右上角“入库设置”里更改。

无论选择哪种方式，重复词都只定位原词条：不会重复加入、不会覆盖释义，也不会重复联网。

Session-only credential

连接专用私有仓库

建议新建一个专用私有仓库，并让令牌只访问该仓库、只授予 Contents 读写权限、设置较短有效期。令牌关闭应用即清除。Git 会保留旧版本历史，请不要同步敏感笔记。
