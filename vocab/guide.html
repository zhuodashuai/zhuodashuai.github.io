使用手册

卓的个人英语单词本，公开给任何人查看。

这是什么

卓遇到值得记的英文词、短语或句子，就整理成一条词条发布出来。

词卡和词典分开。首页搜索已收录的学习词卡；中英查词无需登录，可查本站打包的中英词典。保存到自己的词本才需要登录，不调用在线翻译或 AI。

访客可以做什么

  • 看 —— 翻阅全部词条，点开看完整释义、例句和出处。
  • 搜 —— 在这个单词本里找词，不是在互联网上查。
  • 筛 —— 按单词、短语、习语、名言等类型过滤。
  • 选词本 —— 进入独立书目，再按章节学习；例如 Never Let Me Go → Chapter 1–23。手机用下拉框选章，也可点上一章、下一章。
  • 复习 —— 先回想英文的意思，再点「显示释义」，最后按「再来一次／有点难／记得／很熟」安排下一次复习。普通查词仍直接显示内容。
  • 听 —— 点词卡的小喇叭朗读；可选英式、美式和慢速。发音说明
  • 带走 —— 导出 JSON，或装成应用离线看。

不用登录，直接用。复习进度保存在当前浏览器，可用页面底部「学习记录备份」导出或恢复；访客不能添加、修改或删除公开词条。

书中原句与佳句收藏

书中收录的词条保留原有学习例句，另外显示「书中原句」。这些英文摘句按所提供的电子版 PDF 核对，并按当前章节匹配；同一个词出现在多章时，不混用另一章的句子。对话中的省略说法保留原样，不补写成虚构的完整句。排版换行已合并，词句没有改写。

原句下方仅显示书名、作者和章节，不显示因版本而异的页码。版本与页码保留作内部核验。参考译意和学习提示是学习辅助，不是已出版中文译本。

切到「原文摘句」可按词本和章节看少量精选佳句，使用原来的搜索框搜索英文、参考译意或学习点；全书范围会包含后面章节的句子，阅读时可先选当前章节。收藏只保存摘句编号，不会把句子加入词本、测试或复习队列。

收藏仅保存在当前设备、浏览器和网站来源。不随账号云同步，GitHub Pages、后端地址、Safari 与主屏幕应用的收藏可能不同。可在摘句区的「收藏备份」导出 JSON，换设备后导入合并；原有收藏保留。学习记录备份不包含佳句收藏，两个入口用途不同。原文资料加载失败不会影响原有词条或学习功能；首次离线无法下载，已缓存新版应用后可离线查看原句和精选摘句。

注册自己的账号与词本

卓本人不需要另注册。继续在原管理页使用 GitHub 登录，再点「我的学习词本」，即可选词学习；也可在个人页选择「卓：使用 GitHub 登录」。这不会把普通账号变成公开词库管理员，也不会更改原来的 GitHub 发布权限。

自己的设备可勾选「保持登录 30 天」。登录凭据只放在安全的 HttpOnly Cookie 中；GitHub 续期信息仅加密保存在后台，不交给网页。最长保留 30 天，退出、重设密码或授权被撤销后仍需重新验证；清除浏览器数据、无痕模式和更换设备也可能需要登录。未勾选时使用短会话。旧会话不能凭空延长，需要下一次正常登录才能启用。

点 我的词本，使用普通用户名和密码注册，不需要 GitHub。用户名为 3–24 位英文字母、数字或下划线，以字母开头，不区分大小写；密码至少 15 个字符，可使用空格和长口令，请勿复用其他网站的密码。

本版不收集邮箱。注册后会显示一次账号恢复码，请复制或下载，保存在只有自己可以访问的地方。忘记密码时可用用户名和恢复码重设密码；重设后恢复码会更新，旧登录会话失效。密码和恢复码都丢失时，不能仅凭用户名找回账号。

登录后可以手动添加英文词或完整短语，填写分点中文释义和备注，也可以先记英文、稍后补充中文。词条只有在服务端确认后才显示保存成功。重复词不会另建一张卡片；另一台设备已修改同一词条时会提示冲突，不自动用旧内容覆盖。第一版每账号最多 1,000 项，并有存储和请求频率限制。

输入英文或中文，按 Enter 查词。英文显示词性与中文释义；中文反查显示可点选的英文结果，结果较多时请输入更具体的词义。常用词使用精简本地索引，其他词和中文反查按需下载本站词典分片，不接第三方 AI、在线翻译或拼写服务。已收录的过去式、复数和书中原文形式可匹配原形；原形完全匹配优先，有歧义不擅自猜测。基础释义来自明确标注的 ECDICT（MIT）；另有卓的公开词条及少量 AI 复核的原创精选义项，不是已完成的七万词原创词典。专业标记保留为词典原注，不当作某章的常用语境义。

中英查词页支持本地拼写建议。英文没有精确结果时，才按需读取本站词头分片，比较漏字、多字、错字和相邻字母颠倒，最多列出五个可点选候选。例如 heppy 可提示 happy；点击才重新查词，不擅自修改输入或收录。正常词、缩写和已知词形优先；短语保留整体，粘贴时末尾多出的逗号或句号可忽略。短输入、复杂专名、长句或不在索引中的词可能没有建议；无上下文不能保证识别所有错误，已是合法词的误用也不会强行纠正。

拼写建议与主查询分开加载，网络失败不妨碍继续输入其他词，也不把服务异常当作拼写错误。候选仅来自本站已有词头，不生成新释义，不调用外部模型；首次离线不能补下载未缓存的索引。该入口目前在公开的中英查词页，个人词本的精确查词和保存流程保持原样。

中文近义找词。中英查词页和个人词本先显示直接释义，再补充最多八项「近义关联」。原有 114 组规则保留，另新增 230 组按词性和具体意思核对的常用关联。新组会显示本次匹配的词性和义项；只使用已核对的词头及原始来源释义，不凭解释中提及、词形相近或共享主题就关联。名词、动词、形容词、副词分别核对，不代表任意语境可直接替换。完整清单和用法范围见下表。

不改写原释义，不代表英语词能随意互换。只识别完整的受支持中文查询，不从长句中猜意思，不把「不开心」改成「开心」，也不把「开心果」当作情绪。多义词、专业词和未列入规则的意思仍使用原检索方式；候选与下载有上限，提示缩小范围不代表词库一定没有。关联不自动收藏或发布，迟到或失败的关联不覆盖已有结果；离线仅能使用已缓存的词典分片，不调用在线模型。

122构成／组成动词form / constitute / make动词：作为部分构成整体；不是 make 的制造、form 的表格。此义的主语通常是组成部分。
123变成／成为动词become / turn动词：由原状态发展为另一状态或身份；turn 不是转弯，成为某种职业通常用 become 更自然。
124相遇／遇见动词meet / encounter动词：人彼此碰面；encounter 通常较正式、常带偶然意味，不包括 meet 的满足要求义。
125带领／引导动词lead / take / guide动词：带人前往某处、为人领路；不是 lead 的铅，也不将所有 take 的拿取义扩展进来。
126制造／生产动词produce / make动词：使人造产品产生；不是 produce 的农产品名词义，make 的迫使或赚取义另计。
127回忆／回想／忆起／记得动词remember / recall / recollect动词：从记忆中想起过去的事；不包括 remember to do 的记得去做，recall 的召回也另属一义。
128去世／死亡动词die / perish / pass away动词：生命终结；pass away 较委婉，perish 常指因事故等丧生，不扩展到物品腐坏或出口。
129保持／保留动词retain / keep动词：让已有事物、位置或特点继续存在；不是 keep 的遵守规则义，retain 较正式。
130工作／职业名词occupation / job / line of work名词：谋生所从事的工作；不是一次零碎任务，也不是 occupation 的占领义。
131包含／含有动词carry / contain动词：内部具有某种内容或成分；carry 仅限含有义，不包含携带或 contain 的遏制义。
132体验／经历动词experience / go through动词：亲自经受某种事情或状态；不包括 experience 作经验的名词义，也不是 go through 的仔细检查。
133安排／整理／排列动词arrange / order动词：给思想、事件等安排次序；order 的命令、订餐以及名词订单不属于此义。
134完全／全然副词wholly / entirely / completely / totally副词：达到全部程度、毫无保留；不是 complete 的完整的形容词，也不把完全等同于几乎。
135句号／句点名词period / full stop名词：句末标点；full stop 常见于英式英语，period 的时期、周期义不在此组。
136后果／结果名词consequence / outcome / result / upshot名词：先前行为或事件造成的结局；consequence 常带不利意味，不能据此关联 result 的产生动词义。
137抑制／约束／遏制动词control / hold in / contain / curb动词：将情绪、行为或事态控制在限度内；contain 的含有、curb 的路缘石不在此组。
138作用／功能名词function / role名词：某人或某物所起的用途、承担的任务；不包括数学函数、正式宴会或演员角色。
139使用／利用／运用动词apply / use动词：把方法、规则、资源用于实际用途；apply 的申请或涂抹不属于本组。
140中央／中心／中间名词center / centre / middle / heart名词：较大区域中大致居中的地方；heart 是比喻的中心，不是解剖学心脏。
141片刻／瞬间名词moment / minute / second名词：不确定的短暂一会儿；minute、second 在此为泛指短时间，不声称分钟与秒的计量长度相同。
142思考／考虑动词study / consider动词：认真思量某个问题或方案；study 不在此表示学科、书房或单纯上学。
143倒塌／垮掉动词collapse / fall in / give way动词：结构支撑失效而塌下；give way 的让路义不在此组。
144扮演／表演动词act / play动词：扮演戏剧中的角色；不是 play 的玩耍、演奏，也不是 act 作法案的名词义。
145延迟／耽搁名词delay / postponement名词：等待某行动发生的延误时段；不是形容词迟到的，也不将所有等待等同于推迟。
146同意／一致动词agree / concur动词：意见一致、赞同某观点；concur 较正式，不包括 agree 的符合尺寸或事物相配义。
147头脑／脑袋名词mind / head / brain名词：思考、感受与推理能力的所在，head、brain 为转喻；不是头部外形或食品脑组织。
148学科／领域名词discipline / subject / field / study名词：知识研究的分支；field 不指田地，discipline 不指纪律处罚。
149案件／诉讼／诉讼案件名词lawsuit / suit / case名词：法院中的诉讼程序或法律案件；不是 suit 的套装，也不是 case 的容器或一般情况。
150分开／分离动词separate / part / split动词：结束彼此联系、关系上分离；split 的劈开物体义和 part 的部分名词义另计。
151停留／逗留动词stay / remain动词：继续留在某个地点或位置；remain 的残余物名词、stay 的延期法律用法不在此组。
152旋律／曲调名词melody / air / strain名词：一系列形成鲜明乐句的音符；air、strain 此义较文学化，air 不是空气，strain 不是压力或拉伤。
153事例／例子／实例名词case / instance / example名词：某类事情的一次具体发生；case 不指箱子，example 在此并非供人模仿的榜样。
154开除／解雇动词fire / dismiss / give the sack动词：终止雇佣或撤去职务；fire 较口语，dismiss 较正式，不含开火、火焰或驳回意见义。
155测试／试验动词test / try / try out动词：通过尝试检查质量、性能等；不是 try 的审讯，也不是仅作名词的试验报告。
156尝试／试图／企图动词try / attempt动词：努力去做某事；try 常接 to do，attempt 较正式，不限于恶意企图，也不是试验名词。
158容忍／忍受／忍耐动词endure / stomach / bear / stand动词：承受不愉快的人或事；stand、stomach 常用于否定，bear 不是熊，stomach 不是胃。
159新闻／消息名词news / word名词：有关近期事情的信息；word 在此取消息义，不取单词、诺言或命令义。
160手段／方法名词means / way名词：达到目的的做法或途径；means 此义单复数同形，不包括财富义，way 不指道路实体。
161度过／消磨动词spend / pass动词：以某种方式用掉时间；不是 spend 的付钱义，也不是 pass 的及格义。
162倾听／听取动词listen / hear动词：认真听别人说话或意见；listen 通常接 to，hear 在此取专心听的义，不等于所有被动听见。
163中断／打断动词break / discontinue动词：使活动或连续状态不能继续；discontinue 常指停止延续，不是 break 的打碎实体。
164展示／展览动词exhibit / present动词：把物品、作品等展示给观众；present 不取礼物或目前的义，exhibit 不取名词展品义。
165承认／认可动词acknowledge / recognize / recognise动词：承认某人所称身份、权力或权威；不包括 recognize 的凭外貌认出，也不是 acknowledge 的致谢。
166描写／描述动词describe / depict / draw动词：用语言或形象描绘对象；draw 仅取描写义，不能引入抽签、拖拉等义。
167分发／分配动词distribute / deal / dispense / allot动词：将物品、份额等分别给予多人；deal 不指做交易，dispense with 的省去义不在此组。
168教导／教育动词teach / instruct动词：传授知识或技能；instruct 较正式，不取命令或委托律师义。
169特别／特殊形容词particular / peculiar / special形容词：某人、事物或类别特有、非一般的；peculiar 不取古怪义，particular 不取挑剔义。
170地基／基础名词foundation / base / substructure名词：承托建筑物的底部结构；foundation 常用复数，不取基金会或化妆品义。
171取出／拿出／拔出动词pull out / take out动词：从容器、遮盖物等处取出；pull out 强调拉出，不是退出；take out 不取带人外出或订购外卖义。
172参观／游览动词visit / see动词：为游览等目的前往某地；see 在此不是理解，visit 不泛指所有拜访某人。
173外形／形态／形状名词form / shape名词：视觉上呈现的轮廓或结构；form 的表格、shape 的身体状况不在此组。
174准备／预备动词fix / prepare / ready动词：使事物为某个用途或行动做好准备；ready 在此作动词，fix 不取修理义。
175熟练／精通形容词adept / expert / proficient / skillful / skilful形容词：具备较高知识和技能；expert 不取专家名词义。adept、proficient 常接 at 或 in。
176削减／缩短动词abridge / abbreviate / shorten / cut动词：保留要点而缩短内容、篇幅或范围；abridge 常用于文本，abbreviate 常用于缩写，不代表所有减少都能互换。
177注意／留心动词heed / mind动词：认真留意或顾及某事；mind 不取思想的名词义，也不等于所有介意义。
178完成／实现／达到动词achieve / accomplish / attain / reach动词：通过努力获得目标或结果；reach 不指伸手，accomplish 更常接任务，不可机械替换所有宾语。
179细节／详情名词detail / particular名词：整体中具体的小部分或资料；particular 此义常用复数 particulars，不是形容词特定的。
180提到／提及动词mention / refer动词：简短说到或写到某事；refer 通常用 refer to，mention 直接接宾语，不是参考文献名词。
181图样／图案名词design / pattern名词：装饰性或艺术性的线条、形状安排；不是 design 的企图，也不是 pattern 的行为模式。
182水平／程度／等级名词degree / grade / level名词：强度、数量或质量量表上的位置；degree 不取大学学位，grade 不取年级或评分动词义。
183发育／生长／成长名词growth / development名词：生物由简单到复杂、逐渐长大成熟的过程；不把经济增长、房地产开发等其他义一并关联。
184对准／瞄准动词aim / train / take aim动词：将武器、相机等指向目标；train 在此为对准，不是训练或火车。
185发现／找到动词discover / find动词：发现此前未知的事实或事物；不是所有找回丢失物品，也不包括 find 的法院裁定。
186榜样／模范名词exemplar / example / model名词：值得他人模仿的人或事物；不是 model 的模型、模特，也不是普通举例。
187处理／应付动词manage / deal / handle动词：负责处理某项事务或情况；deal 通常用 deal with，不取交易名词或发牌义。
188消耗／花费动词spend / expend动词：付出金钱、时间或精力等资源；expend 较正式，不包含 spend time 的单纯度过时间义。
189强制／强迫／迫使动词coerce / pressure / force动词：通过压力或必要性使人做不愿做的事；coerce 常接 into doing，force 常接 to do，不是 force 的力名词。
190夜晚／夜间／晚上名词night / nighttime名词：日落后至日出前的黑暗时间；不是文学上以夜晚指代忧暗处境，也不是晚餐。
191享受／欣赏／爱好动词love / enjoy动词：从某活动或事物中获得愉悦；love 此义不等于爱情，爱好在此作动词，enjoy 可接名词或动名词。
192出版／发行／发表／发布动词publish / bring out / issue / release动词：把作品或信息准备好并公开发行；release 的释放囚犯、issue 的问题名词义不在此组。
193买卖／交易名词deal / trade / business deal名词：一次具体的买卖交易；不是贸易行业总体，也不是 deal 的分发或处理动词义。
194唤起／引起动词arouse / elicit / kindle / evoke动词：引发情绪、感受或反应；kindle 在此为比喻，不是点燃实物；elicit 常强调从他人引出反应。
195形成／成形动词form / take form / take shape动词：逐渐成为有形态或结构的事物；take shape 常用于想法、计划，不取体育体形义。
196主席／会长名词chairman / chair / chairperson名词：主持组织会议的人；chair 不指椅子实体，chairperson 为不限定性别的表达，不等同于所有国家领导职位。
197不足／缺乏名词lack / deficiency / want名词：所需东西不存在或不够的状态；want 在此不是想要的动词，不等于个人愿望。
198供应／供给／提供动词supply / provide / furnish动词：给予有用或需要的东西；furnish 不局限配家具，supply 不取供给量名词义。
199程序／手续名词procedure / process名词：为达到某结果所采取的步骤或办事程序；不是计算机进程或生物生长过程。
200匹配／符合动词match / fit / correspond动词：性质相容或彼此一致；fit 不取安装或痉挛义，correspond 不取通信义。
201评价／评估／评定动词evaluate / assess / appraise / value动词：判断性质、质量、能力或价值；value 不取珍爱义，也不把所有估价与最终定价完全等同。
202临近／接近／靠近动词approach / near / draw near动词：在空间上朝目标移动、距离缩短；approach 不取处理问题的方法名词义。
203操作／操纵动词operate / control动词：使机器、设备等运行；operate 的做手术、control 的泛指限制情绪义不在此组。
204交换／兑换动词exchange / change / interchange动词：彼此交出并接收相应事物；货币常用 exchange 或 change，不能将 change 的一切变化义引入。
205意图／目的名词purpose / intent / intention / aim名词：计划行动所追求或预期的结果；aim 不取瞄准动词义，purpose 不等于所有客观功能。
206采用／采纳／遵循动词adopt / follow动词：接受并遵循理论、政策、策略等；adopt 不取收养，follow 不取跟随行走。
207意见／见解名词opinion / view名词：针对某事所持的看法；view 不取风景或观看动词义，意见不是已经证实的事实。
208艰苦／费力／费劲形容词arduous / hard / laborious形容词：需要付出大量体力或努力的；hard 不取坚硬，laborious 不指所有有报酬的劳动。
209捐助／捐献动词contribute / chip in动词：为某事业提供财物或出一份力；chip in 较口语，不取插话义，contribute 不取投稿义。
210地方／地点名词place / spot名词：相对于地理环境确定的一处位置；spot 不取斑点或发现动词义。
211揭露／泄露／透露动词disclose / reveal / divulge动词：使原先少数人知道或应保密的信息为人所知；disclose 未必有恶意，不把 reveal 的门侧名词义引入。
212兵器／武器名词weapon / arm名词：战斗或狩猎使用的器具；arm 此义常用复数 arms，不是身体手臂。
213履行／遵守动词observe / keep动词：按规则、习俗、承诺行事；observe 不取观察义，keep 不取储藏或保留物品义。
214举动／举止／行为名词behavior / behaviour / conduct名词：人的行事方式与行为表现；conduct 不取指挥或导电动词义，behavior/behaviour 为美英拼写。
215传导／传递动词conduct / carry动词：充当介质传递声音、热、电等；conduct 不取行为名词或指挥乐队义，carry 不扩展到所有携带。
216有关／涉及动词pertain / relate / concern / bear on动词：与某事相关；pertain/relate 常接 to，bear on 强调有关联，不把 concern 的担忧义算入。
217得到／获得动词get / acquire动词：取得具体或抽象事物；acquire 较正式，get 的到达、变得等义不在此组。
218叫喊／呼喊／大叫／尖叫动词shout / cry / call / yell / scream动词：突然大声喊出；scream 更强调尖厉，不表示其余各词都必然是尖叫；call 不取打电话，cry 不限于哭泣。
219叫声／喊声名词cry / yell / shout名词：大声发出的喊声；不把哭泣的泪水或相应动词词性直接混为本组。
220计数／计算动词count / number / enumerate动词：逐一确定数量、点数；enumerate 较正式，不等于所有算术运算，number 不取号码名词义。
221措施／步骤名词measure / step名词：为推进某目标采取的一项行动；measure 不指尺寸、step 不指台阶实体。
222婚姻／婚姻生活／结婚生活名词marriage / matrimony / wedlock名词：已婚关系或已婚状态；matrimony、wedlock 较正式，不是婚礼仪式。
223传送／运送动词transport / carry动词：以车辆、手或身体支撑而把人或物从一处移到另一处；不将 carry 的含有或数学进位义引入。
224路径／路线／轨道名词path / track / course名词：物体移动所循的线或路线；course 不取课程或一道菜，track 不取音乐曲目。
225抨击／攻击动词attack / assail / assault动词：用言语或文字猛烈批评；不是实际武力袭击，assault 此义较强烈、较正式。

228任命／委派动词appoint / name / nominate动词：赋予某人职务或任务；nominate 此处为任命义，不能把仅提名候选人等同于已获任命。

在其他设备打开同一个「我的词本」地址并登录同一账号，可以读取已保存的词条及云端复习记录，各账号互相独立。导出备份只包含当前账号的词条和学习记录，不含密码、恢复码或登录凭据；导出文件为明文，请自行妥善保管。删除个人账号前建议先导出，删除不会影响公开词库或其他账号。

保存到云端需要联网。网络失败时页面不会假装已同步，尚未提交的输入只在当前页面中保留；刷新或关闭前请先复制备份。退出失败时本机页面保持锁定，但服务端会话可能仍未撤销，恢复联网后请重新登录并完成退出。个人页只缓存空白静态外壳，不提供无需登录查看私人词条的离线模式。

「我的词本」的云端学习记录与公开章节的本机复习、测试、随手记分别保存；旧记录不会自动归给新注册账号，也不会被清除。个人页暂不包含初高中词表、个人章节四选一测验、旧学习记录迁入或个人词条 AI 整理。GitHub Pages 与个人页属于不同来源，已安装的公开页应用可能会在浏览器中打开个人页。

随手记：先记词，稍后整理

听到或读到生词时，点顶部「随手记」，直接在空白页输入。例如一行记一个词或短语，Enter 正常换行，也可粘贴多行。文字随输入保存在当前设备，不查词、不调用 AI、不消耗 AI 额度；它们不会自动进入公开词库、章节或复习队列。

稍后点「复制这页」，把内容粘贴给 ChatGPT 或发给我，再进行翻译、核对和正式收录。复制只放到剪贴板，不会自动发送。也可导出这页的文字文件；存储失败时这两个按钮仍可帮助保住尚未保存的输入。

随手记的 JSON 备份只包含便笺，不包含登录、词库草稿或学习记录。恢复时保留本机内容，遇到同 ID 不同文字会另存副本，不用旧备份覆盖新内容。请在随手记页使用它自己的备份入口；词库导出及「学习记录备份」不包含便笺。

公开页与管理页的「随手记」统一进入 GitHub Pages 上的同一个页面，避免平常记到两处。便笺仍仅存在当前浏览器或应用的本机存储中，不会自动同步到 GitHub、手机或其他浏览器；直接使用其他来源地址、浏览器或独立应用时，存储也可能不同。换设备或地址时，请导出备份再导入。已缓存新版应用后，随手记可离线打开和记录；首次访问仍需联网下载页面。两窗口同时改同一页时，会保留不同内容为副本，不静默覆盖。

测试、错词与学习记录

选择具体章节后，右下角「开篇测试」提供英文到中文的随机四选一。每题自动保存，退出后可继续；历史中保留每轮正确率与错词。完成后可只练本轮错词，也可在测试菜单查看累计待练错词。练习答对会移出待练列表，后来再次答错仍会重新出现。测试与记忆复习分别记录，互不更改排程。

页面底部「学习记录备份」会导出本机的复习排程、学习历史和所有章节测试。把文件传到另一台设备，在那里选择文件，先核对预览，再点击「合并这些记录」。本机较新或冲突的记录会保留；相同文件可重复合并。旧版导出的章节测试 JSON 也能通过这个入口恢复。

词库导出和管理页的草稿备份用途不同，不能代替学习记录备份。此功能通过文件迁移，不会自动云同步；GitHub Pages、管理页、Safari 和主屏幕应用的本机记录可能彼此独立。请在实际学习的页面导出，并妥善保存文件。合并不完整时会说明哪一类未成功，可以重试。

首页进度显示「已学习」表示至少评分过一次，不代表已经完全掌握。到期数量会在页面可见、重新打开及切回时更新，离线仍可复习。手机低频筛选与发音设置收在「筛选与发音」中。

单词发音

词卡与详情页的小喇叭都能朗读英文单词或完整短语；再点一次停止，换词会停止上一条，不会叠着播放。关闭详情、切换章节或离开页面也会停止。学习 / 复习时可直接用详情页的小喇叭，不改变你的复习记录。

「发音设置」可选英式优先或美式优先，以及正常或 0.75× 慢速；设置只记在当前设备的这个浏览器。默认优先英式；如果没有对应声音，会说明实际使用的英语口音。声音清单由操作系统与浏览器提供，各设备的音色可能不同。

这是系统合成语音，不是真人录音，也不是词典逐义项校对过的音频。同形异音词的读法可能需要结合语境核对。朗读不用麦克风、不需要 AI key、不消耗本站 AI 额度。

离线朗读需要设备已安装本地英语语音；部分声音由系统的在线语音服务生成，可能会把当前朗读文字发送给该语音提供方。本功能不会发送你的复习记录或整个词库。没有可用英语语音或播放出错时，页面会提示原因。

iPhone 请在 Safari 或已安装的单词本中，保持页面在前台并亲自点击小喇叭。若无声音，检查音量、蓝牙 / 耳机输出及系统英语语音。暂不提供锁屏连续播放；手机上的实际音色和离线可用性请以真机为准。

技术说明：设备语音列表、本地与在线语音。

章节开篇测试

进入具体 Chapter，点右下角的「开篇测试」。每轮覆盖该章节能组成四个可区分选项的词条：看英文，选择本章中的中文意思。题目和选项都会重新随机排列，不受搜索框或类型筛选影响，也不会额外加入生词。

选择答案后自动保存，再显示正误；点「下一题」继续。退出或刷新后，可以从「继续上次测试」接着做。每轮保存开始时间、答题进度、正确率和错词；「测试记录」可以查看以往各轮，也可导出本章记录。未完成的一轮只按已答题计算正确率。

题目使用已收录的章节释义，不调用 AI，并尽量避开释义重叠的选项；不足四个可区分选项的词会明确列为未出题，不计入成绩。新增或改过的词条从下一轮生效，进行中的题目不会中途变化。

测试记录只保存在当前设备的这个浏览器或安装的应用里，不上传 GitHub、不跨设备同步。清除网站数据、无痕窗口关闭或系统清理存储可能导致记录丢失，请按需导出备份。测试不会修改「学习 / 复习」的既有排程。

词条怎么来的

卓用 GitHub 登录后输入英文，AI 整理成草稿，他逐条核对改好，再发布到 GitHub。释义与例句等正文仍由卓确认发布；发布不会触发同义词自动识别。

书籍章节清单可以按固定模板一次导入：规范词条、书中原文形式、中文释义、章节语境和来源会一并核对；再次导入同一章会补齐新词并更新已核对的内容，不会重复造词条。

Never Let Me Go 第三章已整理 28 条：保留原有 16 条划线词，结合原文照片补充 12 条实用表达和写作、描写词汇。补充词不冒充原有划线词；每条均保留原文形式、页码和限定在第三章内的语境。

Never Let Me Go 第四章已整理 51 条：原有 11 条划线词，加上卓明确确认补充的 40 条，均结合第 37–48 页照片校读，保留页码、原文形式与已提供的英式音标。完整学习短语若由划线部分结合语境补全，会在章节说明中注明；双语例句是学习用自拟句，不是小说原文。

第五章对照第 49–60 页照片，精选 18 项：4 项划线词和 14 项补充，兼顾阅读难词、写作用词与实用表达。保留卡片的原有身份和复习记录，其他章节不变；原先宽泛收录的候选词已备份，可按需恢复。按阅读顺序展示，中文释义分点；原文短片段与自拟练习例句明确区分。未核实的音标不补写，第六章不在本次范围内。

几条固定规矩

  • 保留原始输入 —— 输进去什么就是什么，不会被悄悄改写。
  • 拼写只建议 —— 看着像拼错也只是提示，改不改由卓决定。
  • 短语当整体 —— jab at 就是 jab at，不会被拆成 jab。
  • 出处不编造 —— 名言找不到可核对的来源，就明确写「未核验」，作者栏留空。
  • 不强行关联 —— 同义词功能暂缓开放，原有关系数据保留，不影响词条、章节和学习记录。

同义词功能暂缓开放

为避免把相关但不同义的词误归一组，现暂停分组、卡片关联展示及后台自动识别。已有合法关系和识别记录保留为历史数据，不再自动扩展，也不作为已核验的关系展示；旧草稿仍保留原有引用校验，不会把未收录的候选发布出去。

已收录词条、原文例句、摘句、章节测试和复习功能照常使用。旧的同义词页面链接会回到单词卡片视图，所选词本和章节不变。

一条词条里有什么

中文释义、英文释义、分义项、双语例句、音标、词性、搭配、易混淆词、词形和标签。名言谚语另带作者、出处和核验状态。

已核验 卓打开原始来源核对过。

候选出处 检索到了线索，但还没人工确认。

未核验 没找到可靠来源，作者和出处留空。

存在争议 来源之间说法不一致。

数据存在哪里

  • 已发布的词条存在 GitHub 仓库里，那是唯一的正本。
  • 没发布的草稿只在卓自己的浏览器里，刷新、关掉、断网都不会丢。
  • 复习记录是私人的，不会公开。
  • 随时可以导出 JSON 备份。
