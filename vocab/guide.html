使用手册

这是卓的个人英语单词本。卓自己收词、整理、发布，页面公开给任何人查看。

这是什么

一个人的单词本，放在网上。卓遇到值得记的英文词、短语或句子，就整理成一条词条发布出来。

它不是在线词典。这里只有卓已经收进来的词，查不了别的。

访客可以做什么

  • 看 —— 翻阅全部已发布的词条，点开看完整释义、例句和出处。
  • 搜 —— 在已发布的内容里找词。搜的是这个单词本，不是互联网。
  • 筛 —— 按单词、短语、习语、名言等类型过滤。
  • 听 —— 朗读词条发音。
  • 带走 —— 导出 JSON，或把网页装成应用离线看。

访客不能添加、修改或删除词条，也不能用它去查这里没有的词。这些都不需要登录，直接用就行。

卓本人怎么录词

  1. 1
    登录

    用 GitHub 登录，只有卓的账号能进。

  2. 2
    输入英文

    敲一个词、短语或句子，AI 整理成候选词条。

  3. 3
    核对

    释义、例句、音标、出处都可以改。AI 的结果只是草稿。

  4. 4
    发布

    确认后写进 GitHub，公开页随即更新。

几条固定规矩

  • 保留原始输入 —— 输进去什么就是什么，不会被悄悄改写。
  • 拼写只建议 —— 看着像拼错也只是提示，改不改由卓决定。
  • 短语当整体 —— jab at 就是 jab at，不会被拆成 jab。
  • 出处不编造 —— 名言找不到可核对的来源，就明确写「未核验」，作者栏留空。
  • 同义词只能是本子里的词 —— 不会凭空冒出一个没收录过的词。

一条词条里有什么

中文释义、英文释义、分义项、双语例句、音标、词性、常见搭配、易混淆词、词形变化和标签。名言和谚语还带作者、出处和核验状态。

已核验 卓打开原始来源核对过。

候选出处 检索到了线索，但还没人工确认。

未核验 没找到可靠来源，作者和出处留空。

存在争议 来源之间说法不一致。

数据存在哪里

  • 已发布的词条存在 GitHub 仓库里，那是唯一的正本。
  • 没发布的草稿只存在卓自己浏览器的本机存储，刷新、关掉、断网都不会丢。
  • 复习记录是私人的，不会跟着公开词库发出去。
  • 随时可以导出 JSON 备份。

关于 AI 和费用

整理用的是 Cloudflare Workers AI 的账户额度，不需要 OpenAI 或 Claude 的 API key。第一款模型结果不合格时，会自动换第二款免费模型再试一次。

每个 UTC 日最多 20 次整理。额度用完时只保留本地草稿，不会自动切换到可能收费的引擎。

这不是永久免费承诺：最终是否产生费用，仍取决于 Cloudflare 账户套餐和同账户其他用量。

隐私

访客只是读一个静态词库，不需要登录，也不会被要求提交任何内容。GitHub 登录只发生在卓自己的管理页面，登录凭据只存在服务端，浏览器拿不到。
